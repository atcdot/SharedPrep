# SharedPrep

A shared event planning tool for coordinating who brings what.

## Features

- **Create events** — title, description, date, and an optional link (e.g. Telegram group)
- **Share via link** — send the join link to friends, they're in with one click
- **Add items** — list everything that needs to be brought, with quantities
- **Claim & assign** — participants claim items themselves, or the creator assigns them
- **My Events** — all your events on one page
- **Telegram login** — sign in with your Telegram account
- **Display name** — set a custom name shown to other participants
- **Telegram DM toggle** — choose whether others can message you on Telegram

## Stack

Go, PostgreSQL, React, TypeScript, Protobuf/Connect-RPC, Docker

Vibecoded with Claude Code and GLM-5.1.
