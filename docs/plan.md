# SharedPrep — Plan

Совместный список подготовки к событиям. Участники накидывают позиции и разбирают кто что несёт.

## Entities

| Сущность | Описание |
|---|---|
| **Event** | Событие (шашлыки, пикник, поездка). Уникальная ссылка для приглашения |
| **Participant** | Участник. Вход по ссылке, без регистрации (cookie/session) |
| **Item** | Позиция: название, количество |
| **Assignment** | Связь Item ↔ Participant (кто несёт) |

## MVP (v0.1)

Backend API + PostgreSQL. Без фронтенда.

### Event

- Создание события (название, дата, описание)
- Генерация shareable ссылки/кода
- Просмотр по ссылке
- Редактирование/удаление автором

### Participant

- Вход по ссылке, ввод имени
- Cookie для повторного входа
- Автор = создатель события
- Список участников

### Item

- Любой участник добавляет позиции
- Название + количество
- Редактирование/удаление своей позиции
- Добавлять можно в любой момент — никаких фаз

### Assignment

- Любой участник берёт позицию на себя (claim)
- Unclaim — отказаться
- Автор может назначать/переназначать
- Claim/unclaim — цельная позиция (без частичного взятия)

### Overview

- Сводка: что распределено, что свободно
- Группировка по участникам

## После MVP

### Теги

- Произвольные теги на позиции: «не обязательно», «если допоздна» и т.п.

### Голосование за позицию

- Добавить позицию и выставить на голосование: нести / не нести
- Участники голосуют, решение по большинству

### Частичный claim

- Взять часть из общего количества (2 из 5 шт)

### Frontend

- React + TypeScript в `web/`

## Технический стек

| Слой | Выбор |
|---|---|
| Backend | Go, Connect-RPC (proto) |
| DB | PostgreSQL + migrations |
| Auth | Cookie-based session |
| Деплой | Docker Compose |
